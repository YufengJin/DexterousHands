# DexterousHands — Install Recipe

Minimum commands to reproduce this container from a fresh clone. Generated by `env-generator` skill.

## Host prerequisites

- Docker (>= 24) and the Compose v2 plugin
- NVIDIA driver >= 470 and the NVIDIA Container Toolkit
- A GPU visible to `nvidia-smi`
- IsaacGym source placed at `<repo_parent>/isaacgym/` (sibling to this repo). `docker/setup.sh` can auto-extract it from the community image on first run.

Run the bundled check before building:

```bash
bash docker/check_prereqs.sh
```

## Build the image

The recommended path for IsaacGym repos is the one-shot setup script, which handles IsaacGym extraction, image build, container start, and editable-install wait:

```bash
bash docker/setup.sh
```

Or build manually:

```bash
docker compose -f docker/docker-compose.headless.yaml build
```

Base image: `nvidia/cuda:11.8.0-cudnn8-runtime-ubuntu20.04`
Python: `3.8` (managed by `uv` in `/opt/venv`)
Install strategy: `uv pip install -r requirements.txt` + explicit `numpy==1.23.0 rl-games==1.5.2` pins

## Bring the container up

```bash
docker compose -f docker/docker-compose.headless.yaml up -d
docker exec -it dexteroushands-headless bash
```

For an X11-enabled session (GUI apps, visualisers):

```bash
xhost +local:docker
docker compose -f docker/docker-compose.x11.yaml up -d
```

Only one of the two profiles may run at a time — they share the container name.

### IsaacGym CPU PhysX smoke test

```bash
python -c "
import isaacgym
from isaacgym import gymapi
gym = gymapi.acquire_gym()
sp = gymapi.SimParams()
sp.up_axis = gymapi.UP_AXIS_Z
sp.gravity = gymapi.Vec3(0, 0, -9.81)
sp.physx.solver_type = 1
sp.physx.use_gpu = False
sp.use_gpu_pipeline = False
sim = gym.create_sim(0, -1, gymapi.SIM_PHYSX, sp)
gym.destroy_sim(sim)
print('CPU PhysX OK')
"
```

> Note: GPU PhysX pipeline (`use_gpu=True`) may SIGSEGV on host driver 570+. This is a
> known IsaacGym Preview 4 limitation on newer drivers and is not a failure of this setup.
> On this host (RTX 4090, driver 570.211.01) GPU PhysX passed.

## Stop / clean up

docker compose -f docker/docker-compose.headless.yaml down

## Additional first-run steps

IsaacGym is installed from the sibling mount at `/workspace/isaacgym` on first container start (via `entrypoint.sh` post-install hook). Ensure the sibling directory exists before running:

```bash
ls ../isaacgym/python/setup.py   # must exist before docker compose up
```

If the sibling is missing, `docker/setup.sh` auto-extracts it from `uvarc/isaacgym:1.0.preview4-cuda11`.
